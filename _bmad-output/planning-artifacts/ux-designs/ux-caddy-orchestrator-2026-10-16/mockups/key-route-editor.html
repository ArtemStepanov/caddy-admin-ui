Immich

Настройки маршрута · общий черновик

Назначение

Сейчас применено: immich:2283. Адрес должен быть доступен из сети Caddy.

Запись DNS настраивается отдельно. Выбор контейнера — желаемый сценарий; способ подключения Docker ещё проектируется.

Тот же кандидат в Caddyfile · альтернативный вид показан ниже для сравнения, а не как отдельная конфигурация.

Фрагмент маршрута в общем черновике

photo.home.example {
    reverse_proxy immich:2284
}

Оба вида изменяют один черновик. Сохранение не публикует изменения.

Показан простой совместимый пример. Для существующих imports, комментариев и сторонних директив сохранение исходника и безопасное переключение требуют отдельного технического контракта.
